## ⚙️ 心跳轮询机制

### 设计架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        nanobot Gateway                          │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │              心跳调度器 (interval: 30 分钟)                │    │
│  │                    【可选组件】                           │    │
│  └─────────────────────────────────────────────────────────┘    │
│                              │                                   │
│                              ▼                                   │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │         pipeline-heartbeat.sh (每 5 分钟执行)             │    │
│  │  - 读取活跃子代理数量                                    │    │
│  │  - 扫描任务状态文件                                      │    │
│  │  - 检查超时任务 → 标记 abandoned                         │    │
│  │  - 启动待执行任务的子代理                                │    │
│  │  - 更新 active-agents.md                                 │    │
│  └─────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────┘
```

### 本地部署状态

| 组件 | 设计状态 | 本地状态 | 说明 |
|------|----------|----------|------|
| nanobot Gateway 心跳 | 可选 | ❌ 未配置 | 本地未启用 Gateway 心跳调度器 |
| pipeline-heartbeat.sh | 核心脚本 | ✅ 已部署 | 脚本存在，但无调用机制 |
| cron 心跳任务 | 可选 | ❌ 未配置 | 当前没有 cron 任务调用脚本 |
| 任务流水线 | 核心功能 | ⏸️ 暂停 | 系统就绪，但心跳未启用 |

### 为什么本地未启用心跳？

1. **开发调试阶段**: 手动控制任务执行更便于调试
2. **资源考虑**: 避免不必要的子代理并发
3. **按需启用**: 有实际任务时再启用心跳机制

### 如何启用心跳

```bash
# 方案 1: 使用 cron (推荐)
nanobot cron add --cron_expr "*/5 * * * *" --tz "Asia/Shanghai" \
  --message "任务流水线心跳检查"

# 方案 2: 配置 nanobot Gateway 心跳
# 编辑 gateway 配置，启用 heartbeat 调度器
```

## 🔒 配置说明

本仓库不保存任何真实的通道 ID、密钥或凭证。部署时请按下表把占位符替换为你自己的值，并只写进本地配置，不要提交。

| 配置项 | 仓库占位符 | 说明 |
|--------|------------|------|
| WORKSPACE | `/path/to/workspace` | 你的工作区目录 |
| Discord Chat ID | `[DISCORD_CHAT_ID]` | 你自己的 Discord 频道 ID，走环境变量传入 |
| 最大子代理数 | `5` | 如无特殊需要保持默认 |

> Discord Chat ID 等通道标识请通过环境变量 `DISCORD_CHAT_ID` 注入，不要写入仓库文件。
