# 流水线运行模式

**最后更新**: 2026-03-05 15:08

---

## 当前模式

**模式**: 正式期

---

## 模式说明

### 搭建期
- 每个阶段完成后等待用户确认
- 失败立即停止并报告
- 详细日志输出
- 每阶段都发送通知

### 正式期
- 自动流转，只确认需求和最终 PR
- 失败直接报告 (不重试)
- 只在 PR 完成时发送通知
- 失败时立即发送通知

---

## 切换命令

- 切换到正式期：`切换到正式期` 或 `pipeline-mode formal`
- 切换到搭建期：`切换到搭建期` 或 `pipeline-mode dev`
